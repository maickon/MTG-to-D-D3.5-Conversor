# Gerador de Criaturas de Magic para D&D 3.5

Ferramenta gratuita para criar fichas-base de monstros de **Dungeons &
Dragons 3.5** a partir de cartas de criatura de **Magic: The
Gathering**.

O gerador utiliza informações da carta --- como nome, poder,
resistência, custo de mana, cor e habilidades --- combinadas com
características adicionais escolhidas pelo usuário, para estimar
atributos, dados de vida, pontos de vida, classe de armadura, ataques,
resistências e habilidades especiais.

## Observações

-   Esta é uma ferramenta independente e não oficial.
-   Os valores gerados são estimativas e podem exigir ajustes pelo
    Mestre.
-   O gerador cria uma ficha-base. Talentos, perícias, idiomas,
    equipamentos, comportamento e outros detalhes podem ser
    complementados manualmente.
-   Magic: The Gathering e Dungeons & Dragons são propriedades de seus
    respectivos titulares. Este projeto é uma ferramenta de fã, sem
    vínculo ou afiliação oficial.

## Tecnologias

-   HTML
-   CSS
-   JavaScript
-   [html2canvas](https://html2canvas.hertzen.com/) para exportação da
    ficha como imagem.

## Utilização

Baixe ou hospede o arquivo HTML para utilizar o gerador. Para
incorporá-lo em um artigo ou página, use um `iframe` apontando para o
endereço público do arquivo.
